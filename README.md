# VNGrocery Admin Web

React + Vite admin UI for the VNGrocery server API.

## Commands

- `npm install`
- `npm run dev`
- `npm run build`
- `docker compose up --build`

## Notes

- Default API base: `http://<host>:8080/v1`
- Session is stored in browser localStorage
- Docker image serves the built app with Nginx
